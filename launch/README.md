# Launch drafts

These are drafts for the owner to edit and post personally. Nothing here is posted automatically, and the pipeline never posts anywhere.

Before posting any of them:

1. Fill in the final name and URL (`site/src/config.ts` is the single source) and replace every `[SITE]` / `[URL]` below.
2. Make sure the blind evaluation has run and the methodology page shows real numbers, or keep the "unverified" wording. Do not claim accuracy that is not measured.
3. Check the numbers (repos, issues, orgs) against `/api/v1/meta.json` on the day you post. The ones below are placeholders in square brackets.
4. Read the rules of each venue in a browser on the day (DEV `#showdev` guidelines; HN "Show HN" rules: usable without signup, no asking for upvotes, one maker comment; subreddit rules for r/opensource and r/learnprogramming were not fetched by the build and must be read first).
5. Keep the AI-use disclosure. The project was built with an AI coding assistant under human direction; say so.

Suggested order (from `PLAN.md`): DEV post days 8–14, Show HN days 15–21, daily.dev source application after the RSS feed has a week of items, awesome-list PRs only where the list's contribution guide accepts new entries.
