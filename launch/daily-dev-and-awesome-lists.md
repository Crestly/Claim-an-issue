# daily.dev source application and awesome-list PRs

## daily.dev

Apply via the "Suggest new source" form in the daily.dev app (review takes up to ~30 days; verify the current process in the app). They want a public RSS feed with regular items.

- Feed: `[URL]/rss/all.xml` (50 newest open issues, refreshed 3×/day). Wait until the feed has at least a week of history before applying.
- Short description (≤ 200 chars): "Newcomer-friendly open-source issues that nobody has claimed yet, with the evidence. Plus every GSoC org mapped to its live GitHub issues."

## Awesome lists

Only open a PR where the list's CONTRIBUTING file accepts new entries and the entry fits the list's scope. Read the guidelines each time; most require the project to be older than 30 days and some require a certain star count. Candidates to check (do not assume acceptance):

- `MunGell/awesome-for-beginners` (projects, not tools; probably not a fit; check)
- `sindresorhus/awesome` sub-lists under "Open Source" or "Contributing"
- `danthareja/contribute-to-open-source` style lists
- lists of GSoC resources maintained by students (search GitHub for "awesome gsoc"; check each one's licence and activity)

Entry line (one-line, no marketing):

`- [SITE]([URL]) - Open-source issues with an evidence-backed open/claimed/stale verdict, and GSoC mentoring orgs linked to live issues. Static, no login.`
